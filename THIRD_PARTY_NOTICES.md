# Third-party software

Chatlog Plus is an independent companion service. It does not include Chatlog binaries,
WeChat databases, decryption keys, media files, speech models, or user data.

- [Chatlog](https://github.com/majin72/chatlog) is distributed under the Apache-2.0 license.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) is distributed under the MIT license.

Users install and run those dependencies separately under their respective licenses.
